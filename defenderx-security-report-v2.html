Summary

개발팀 사용자가 외부에서 다운로드한 파일 실행 시도가 탐지되었습니다. 해당 파일은 정상적인 개발 도구로 위장한 악성 실행 파일로, WildFire 분석 결과 Malware로 판정되었습니다. XDR 에이전트가 파일 실행을 사전 차단하여 실제 피해는 발생하지 않았으나, 동일 파일이 3건의 추가 Alert와 연관되어 있어 내부 확산 시도가 있었던 것으로 추정됩니다.

주요 공격 기법 (MITRE ATT&CK)
T1204.002 User Execution: Malicious File T1036.005 Masquerading: Match Legitimate Name T1059.001 PowerShell

공격자는 정상적인 개발 도구(VS Code)의 설치 파일명을 모방하여 사용자가 의심 없이 실행하도록 유도하는 Masquerading 기법을 사용했습니다. 파일 실행 시 PowerShell을 통해 추가 악성코드를 다운로드하고, 지속성 확보를 위한 레지스트리 수정을 시도하는 것으로 분석되었습니다. 이는 초기 접근(Initial Access) 이후 실행(Execution) 단계로 진행하려는 전형적인 공격 패턴입니다.

권장 조치

1. 즉시 조치: 해당 호스트에서 동일 해시 파일이 다른 경로에 존재하는지 전체 디스크 스캔을 수행하고, 발견 시 즉시 격리 처리하시기 바랍니다.

2. 확산 방지: 탐지된 SHA256 해시를 전사 EDR 정책에 블랙리스트로 등록하여 다른 호스트에서의 실행을 사전 차단하시기 바랍니다.

3. 근본 원인 분석: 사용자가 해당 파일을 다운로드한 경로(웹사이트, 이메일, 메신저 등)를 확인하고, 해당 다운로드 소스를 웹 필터링 정책에 추가하시기 바랍니다.

4. 사용자 교육: 개발팀 대상으로 공식 소프트웨어 배포 채널 이용 안내 및 비공식 다운로드의 위험성에 대한 보안 인식 교육을 실시하시기 바랍니다.

Summary

인사팀 사용자의 워크스테이션에서 알려진 C2(Command & Control) 서버로 의심되는 외부 도메인으로의 아웃바운드 연결 시도가 탐지되었습니다. 해당 연결은 피싱 메일에 포함된 링크 클릭으로 인해 발생한 것으로 추정되며, 네트워크 방화벽에서 해당 통신을 차단하여 실제 데이터 유출은 발생하지 않았습니다. 목적지 IP는 러시아 소재 호스팅 업체로 확인되었으며, Threat Intelligence 조회 결과 Cobalt Strike C2 서버로 알려진 IOC입니다.

주요 공격 기법 (MITRE ATT&CK)

본 인시던트는 스피어피싱 링크를 통한 초기 접근 시도로 분석됩니다. 공격자는 정상적인 CDN 또는 분석 서비스로 위장한 도메인을 사용하여 보안 솔루션의 탐지를 우회하려 했습니다. 목적지 서버는 HTTPS(443 포트)를 통해 통신하며, 이는 정상 웹 트래픽으로 위장하여 네트워크 모니터링을 회피하기 위한 전형적인 C2 통신 패턴입니다. 해당 도메인은 최근 Cobalt Strike 비콘 배포에 사용된 것으로 Threat Intelligence에서 확인되었습니다.

권장 조치

1. 네트워크 차단: 탐지된 도메인(cdn-update.malicious-domain.ru, api.tracker-analytics.com) 및 IP 주소를 방화벽과 프록시 서버의 블랙리스트에 등록하여 전사적으로 접근을 차단하시기 바랍니다.

2. 호스트 점검: 해당 사용자의 워크스테이션에서 악성코드 전체 스캔을 수행하고, 브라우저 확장 프로그램, 시작 프로그램, 예약된 작업 등 지속성 메커니즘이 설치되어 있는지 확인하시기 바랍니다.

3. 로그 분석: 지난 7일간 동일 목적지로의 통신 시도가 다른 호스트에서도 발생했는지 네트워크 로그를 분석하여 추가 감염 호스트가 없는지 확인하시기 바랍니다.

4. 사용자 대응: 해당 사용자에게 피싱 메일의 발신자, 제목, 내용을 확인하여 보안팀에 전달하도록 안내하고, 동일한 피싱 메일이 다른 사용자에게도 전달되었는지 이메일 로그를 조회하시기 바랍니다.

5. TI 공유: 탐지된 IOC(도메인, IP, URL)를 내부 Threat Intelligence 플랫폼에 등록하고, 필요시 ISAC 또는 유관기관과 정보를 공유하시기 바랍니다.
